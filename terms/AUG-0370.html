Animal-Care Query

A use episode in which a person queries an AI system for information about animal care - feeding, behaviour, preventive health, or species-appropriate husbandry. The referent is a topically defined everyday information request.

Operational Definition

EVENT. One occurrence is recorded when a user query is classified as seeking animal-care information, identified by topical markers (species terms together with care intents such as feeding, health signs, behaviour, or housing). Each qualifying query counts as one instance.

Measurement Schema

Proposed measurement protocol (not yet empirically validated): Query-topic classification: a held-out sample of user queries is labelled against an animal-care topic taxonomy by two annotators; prevalence could be reported as the proportion of queries in this topic class and as queries per active user per month. Annotation reliability via Cohen's kappa; optional automated classifier validated against the human labels (precision/recall, F1).

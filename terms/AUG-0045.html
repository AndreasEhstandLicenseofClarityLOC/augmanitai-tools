Indexical Memory (AUG-0045)

The shift of the memory function from content knowledge to knowledge about storage location. The user no longer remembers the information itself but where and how to retrieve it via AI. Describes a fundamental shift in personal knowledge management in the AI era. Related to AUG-0014 (The Extended Mind Map) and AUG-0015 (The Outer Mind).

Operational Definition

Indexical Memory is observed when participants retrieve session-specific content via deictic markers (this, that, here, then) rather than via content-features, with successful retrieval rate measured against ground-truth transcript references.

Measurement Schema

Hidden Markov Model state-transition probabilities estimated over deictic-marker sequences: states are deictic categories (proximal-temporal, distal-temporal, proximal-spatial, distal-spatial), transitions capture indexical-retrieval patterns. Retrieval-success rate = correct ground-truth match within 3-turn window.

Inclusion criteria

At least 10 deictic markers per session with verifiable transcript anchors.

Exclusion criteria

Deictic uses lacking identifiable referent in the transcript.

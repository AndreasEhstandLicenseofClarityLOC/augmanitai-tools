The Role-Aware Input (AUG-0675)

An input pattern in which the user incorporates social roles into the formulation — "As a parent I need…," "In my function as…." The input is contextualized through the user's role. Related to AUG-0491 (The State Label), AUG-0650 (The Context-Sensitive Query), and AUG-0524 (The Context Layer).

Operational Definition

Role-Aware Input is observed when participants adapt prompt-formulation based on an explicit AI-role assignment (e.g., teacher, critic, brainstormer), measured by detectable lexical and syntactic shifts across role-conditions.

Measurement Schema

Mann-Whitney U test on lexical-feature distributions (formality, hedging, directiveness) between role-conditions within-participant. Role-awareness detected when at least 3 features differ significantly across roles at Bonferroni-corrected p < 0.01.

Inclusion criteria

Participant uses at least 3 distinct AI-roles within the observation window.

Exclusion criteria

Sessions where role-assignment is implicit only (no explicit role-string).
